    LESSON 0002 · SDK

    SDK 最小接入：跑通第一条 Trace

    预计 20 分钟 · 难度 ★★☆☆☆ · 产出：UI 上看到第一条 hello trace
    本节目标
    用 @observe 装饰器 + langfuse.openai auto-instrumentation，把一次最简单的 OpenAI 调用埋点。跑完后回到 UI 能看到一条完整的 Trace，含输入、输出、模型、token。

    1. 装依赖

    pip install "langfuse>=3.0" openai python-dotenv

    确保你 lesson 1 里的 .env 文件在本目录，4 个变量都有。

    2. 第一个脚本

    新建 hello_trace.py，逐行敲一遍（别复制粘贴，敲的过程会注意到细节）：

    # hello_trace.py
import os
from dotenv import load_dotenv
load_dotenv()

from langfuse import observe
from langfuse.openai import openai   # ← 注意：不是 import openai

@observe()                          # ← 装饰器，标记一个 Trace
def ask(question: str) -> str:
    resp = openai.chat.completions.create(
        model="gpt-4o-mini",
        messages=[{"role": "user", "content": question}],
    )
    return resp.choices[0].message.content

if __name__ == "__main__":
    print(ask("一句话讲清楚什么是 Langfuse。"))
    from langfuse import get_client
    get_client().flush()             # ← 短脚本必加，否则 trace 还没发出去进程就退了

    三个关键点（划重点）

    关键为什么
    from langfuse.openai import openai这是 Langfuse 的 OpenAI 兼容客户端。任何用这个 client 发的请求都会被自动埋点成 Generation 节点。
    @observe()包在函数外，标记一个 Trace。函数内部的 LLM 调用会作为子节点挂在这个 Trace 下。
    get_client().flush()SDK 是异步上报的。脚本进程退出前如果不 flush，最新一条 trace 可能丢失。生产服务一般不用调。
    ⚠️ 坑：很多人写 import openai，这是错的——那是原生 OpenAI SDK，Langfuse 拦截不到。必须 from langfuse.openai import openai，得到的对象是 Langfuse 包装过的"看上去一样、用起来一样、但会顺手上报 trace"的版本。
    ⚠️ 坑（非 OpenAI 提供商）：如果你用 Azure / 本地代理 / MiniMax / DeepSeek 等 OpenAI 兼容协议，langfuse.openai 拿到的 client 默认只读 OPENAI_API_KEY / OPENAI_BASE_URL，而你的 env 名往往是别的（比如 MINIMAX_API_KEY）。修法：要么在脚本顶部桥接 env 变量，要么显式 OpenAI(api_key=..., base_url=...) 构造客户端。详见 learning-record 0006。

    3. 跑起来 + 看 UI

    python hello_trace.py

    看到控制台打印答案后，浏览器切到 localhost:3000 → 项目 agent-sandbox → 左侧 Tracing。你应该看到一条这样的记录：

    Trace: ask
└─ Generation: gpt-4o-mini
   ├─ input:  [{role:user, content: 一句话讲清楚…}]
   ├─ output: Langfuse 是一个开源的 LLM 可观测性…
   ├─ tokens: 47 in / 31 out
   └─ latency: 1.2s

    如果没看到，最常见两个原因：

    • 忘了 flush()，或进程被杀得太快
    • API Key 拷错了 → 看终端有没有 401

    4. 关键 SDK 概念提前剧透

    这节课只用到了 @observe 和 langfuse.openai。后面会用到的：

    API用途用在哪节课
    get_client().update_current_trace(...)给 Trace 加 user_id / session_id / tags / metadataLesson 4
    @observe(as_type="generation", name="...")把任意函数标成 Generation 而不是 SpanLesson 3
    get_client().start_as_current_observation(...)上下文管理器，比装饰器更灵活Lesson 3
    propagate_attributes(...)把 user_id 等属性传递到所有子 ObservationLesson 4
    get_client().score(...)给 Trace 打分Lesson 5
    🎯 动手任务（10 分钟）
    1. 把上面的 hello_trace.py 跑通，确认 UI 出现一条 Trace
    2. 改一下 ask()，让一次调用里嵌套两次 OpenAI 请求（比如先问"首都是哪"，再问"写一首关于这个首都的诗"）。观察 UI 中两个 Generation 如何挂在同一个 Trace 下
    3. 在 UI 上点开这条 Trace，记录你看到的字段：input / output / model / tokens / latency

    5. 一句话总结

    两个 import + 一个装饰器 + 一次 flush = 第一条 Trace。
